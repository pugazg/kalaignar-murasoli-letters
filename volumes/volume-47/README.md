- மூல PDF intake, SHA-256, byte size மற்றும் page count பதிவு செய்யப்பட்டுள்ளன.

- PDF பக்கங்கள் **18–22** அடிப்படையில் முழு அச்சு உள்ளடக்க அட்டவணை **3647–3705** தனியாகப் பாதுகாக்கப்பட்டுள்ளது.

- முதல் கடிதம் **3647 — “நடுநிலை, நியாயம், மனசாட்சி - இவை என்னாவது?”** முழுமையாகப் பதிவு செய்யப்பட்டுள்ளது (PDF 24–30; அச்சுப் பக்கங்கள் 23–29).
