## Style lock

The representative pilot and sequential batches confirm these conventions for Volume 48:

- retain **Udanpirappē** and **With affection, M.K.**;
- retain `lakh`, `crore` and **Rule 110**;
- preserve argument order, accusation, irony, repetition and rhetorical questions;
- keep reported allegations attributed to the speaker or publication named by the source;
- retain intentional source English exactly when it is already printed in English;
- use minimal notes for source anomalies, institutional terminology and culturally difficult idiom;
- never use the English translation to normalise or correct the audited Tamil.
