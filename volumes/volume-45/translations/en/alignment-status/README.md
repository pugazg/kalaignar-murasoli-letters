# Machine-readable bilingual alignment status

This directory records batch-level machine-readable bilingual-alignment closure without changing the source-checked drafting status of the bilingual letter bodies.

The human-readable `BILINGUAL_ALIGNMENT_REVIEW_*.md` report is the detailed QA record. A sidecar YAML file records the same batch result in a compact machine-readable form. Canonical Tamil remains controlled by the audited `pages/` layer and the source scan.
