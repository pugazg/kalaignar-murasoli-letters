## Standard bilingual layout

Every letter contains:

1. source/translation metadata;
2. English title;
3. the standard translator’s note;
4. canonical source links and date;
5. complete English translation;
6. only necessary letter-specific notes;
7. the complete audited Tamil under **Original Tamil — மூலத் தமிழ்**.

`Udanpirappē` is retained as Kalaignar's distinctive address. The standard closing is **With affection, M.K.**
